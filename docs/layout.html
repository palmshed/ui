Layout

Navigation, hero, page container, footer, and mobile menu.

Navigation

A horizontal <nav> with a brand mark and vertical <ul> link list.

<nav>
  <span class="nav-mark">palmshed</span>
  <ul class="nav-links" id="nav">
    <li><a href="/" class="active">Home</a></li>
    <li><a href="/docs">Docs</a></li>
  </ul>
  <button type="button" class="mobile-menu-toggle"
          aria-label="Menu" aria-expanded="false">Menu</button>
</nav>

Usage

  • Use class="active" on the current page link.
  • Links use transition: none for instant state changes.
  • The .mobile-menu-toggle button is hidden on wide screens via display: none.

Hero

Page header with a title and optional description. Centered with max-width: 960px.

<div class="hero">
  <div class="hero-content">
    <h1>Page title</h1>
    <p>Short description.</p>
  </div>
</div>

Page container

Wrap body content in .page. Use <section> to separate content blocks.

<div class="page">
  <section>
    <h2>Section title</h2>
    <p>Content.</p>
  </section>
</div>

Sections are spaced 3.5rem apart. .page is capped at 680px for readability.

Footer

Simple footer with copyright and link list.

<footer>
  <p>&copy; 2026 Palmshed</p>
  <ul class="footer-links">
    <li><a href="https://github.com/palmshed">GitHub</a></li>
  </ul>
</footer>

Mobile menu

The mobile menu script toggles .active on the nav links and syncs the aria-expanded attribute. Pressing Escape closes the menu and returns focus to the toggle button.

<script>
(function() {
  var toggle = document.querySelector('.mobile-menu-toggle');
  var nav = document.getElementById('nav');
  if (!toggle || !nav) return;
  function sync() { toggle.setAttribute('aria-expanded', nav.classList.contains('active')); }
  toggle.addEventListener('click', function(e) {
    e.stopPropagation();
    nav.classList.toggle('active');
    sync();
  });
  document.addEventListener('click', function(e) {
    if (nav.classList.contains('active') && !nav.contains(e.target) && e.target !== toggle) {
      nav.classList.remove('active');
      sync();
    }
  });
  document.addEventListener('keydown', function(e) {
    if (e.key === 'Escape' && nav.classList.contains('active')) {
      nav.classList.remove('active');
      sync();
      toggle.focus();
    }
  });
})();
</script>
