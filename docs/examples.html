React / Next.js

Import palmshed/ui CSS files directly in your React components. The following imports assume the @/ path alias is configured to resolve to the project root.

import '@/ui/css/tokens.css';
import '@/ui/css/base.css';
import '@/ui/css/layout.css';
import '@/ui/css/typography.css';
import '@/ui/css/components.css';

For full details, see react-example.md.

Using the templates

Copy a template from templates/ into your project. Adjust the CSS paths to match your deployment. Add your content to the hero, page sections, and footer.

Custom builds

Since palmshed/ui has no build step, you can import the CSS files directly in any setup that supports CSS imports: Webpack, Vite, Parcel, or plain <link> tags. There are no npm dependencies to install.
