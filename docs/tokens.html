Design tokens

All CSS custom properties in palmshed/ui, their values, and when to use them.

Token reference

TokenValuePurpose
--bg #080909 Page background color.
--surface #0e1010 Card, nav, and elevated surface backgrounds.
--text #e1e2e2 Primary text color.
--muted #8f9191 Secondary text, captions, metadata.
--accent #91AAA6 Links, active states, interactive elements.
--border rgba(255,255,255,0.04) Subtle border color for cards and inputs.
--code-bg rgba(255,255,255,0.015) Background for inline <code> and <pre> blocks.
--font -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, ... Primary font stack (system fonts).
--mono ui-monospace, SFMono-Regular, "SF Mono", Menlo, Consolas, ... Monospace font stack for code.

Usage

Use tokens in your own CSS by referencing the variable:

.my-element {
  background: var(--surface);
  color: var(--text);
  border: 1px solid var(--border);
}

Guidelines

  • Use --text for body copy, --muted for less prominent text.
  • Use --accent only for interactive elements and links.
  • Use --surface for elevated containers (cards, nav).
  • Use --border sparingly - prefer spacing to separate content.

Token policy

Tokens are stable after v1.0.0. Renaming or removing a token is a breaking change. Adding a new token is non-breaking.
