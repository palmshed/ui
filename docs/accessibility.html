Accessibility

Every component and template is designed to be accessible by default.

Built-in features

Keyboard navigation

All interactive elements are native HTML elements (<a>, <button>, <input>) and are keyboard accessible without additional scripting. The mobile menu supports Escape to close and returns focus to the toggle button.

Focus states

Base styles provide a visible :focus-visible outline using the accent color:

:focus-visible {
  outline: 1.5px solid var(--accent);
  outline-offset: 2px;
}

Focus outlines are only shown when navigating via keyboard, not on mouse click, thanks to :focus-visible.

Color contrast

All token combinations meet WCAG AA contrast requirements:

CombinationRatioPasses AA
--text on --bg~14.4:1Yes
--muted on --bg~6.7:1Yes
--accent on --bg~6.6:1Yes

Reduced motion

The design system uses minimal transitions. The transition: none rule on nav links means no motion is triggered by default. No animations or keyframe-based effects are used.

Zoom compatibility

All sizing uses relative units (rem, clamp). Pages remain readable at 200% browser zoom with no content loss or horizontal overflow.

Component guidance

Navigation

  • Uses semantic <nav> element.
  • Mobile toggle has aria-label and syncs aria-expanded.
  • Link list uses <ul> for screen reader structure.
  • Escape key closes mobile menu.

Cards

  • Linked cards use a single anchor - no nested interactive elements.
  • Card content is structurally grouped with .card container.

Buttons

  • Semantic HTML - never <div> as button.
  • Visible focus state.

Inputs

  • Supports :focus with accent border.
  • Works with native form labels.

Alerts

  • Supports role="alert" and role="status" for dynamic content.

What to verify when using palmshed/ui

  • Headings follow a logical hierarchy (h1 > h2 > h3, no skips).
  • Each page has one h1 matching the page title.
  • Interactive elements are keyboard accessible.
  • Form inputs have associated <label> elements.
  • Images and SVG icons have appropriate alt text.
  • Content is readable at 200% browser zoom.
  • Test with a screen reader (VoiceOver, NVDA, or JAWS).
