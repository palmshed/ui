Templates

11 HTML starting points for common page types. Each is a complete, accessible HTML document.

Every template includes the nav structure, hero, page container, footer, and mobile menu script. Open any template below to view or use it as a starting point.

Page templates

Creating a new template

Copy an existing template and modify the content. Follow the existing structure:

  • Include only the CSS files the page needs.
  • Use the standard nav, hero, .page, and footer layout.
  • Add the mobile menu script before </body>.
