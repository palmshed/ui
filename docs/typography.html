Typography

Headings, body text, code blocks, tables, and links.

Headings

Six levels of headings with consistent weight and sizing. Uses font-weight: 500 throughout.

<h1>Heading 1</h1>
<h2>Heading 2</h2>
<h3>Heading 3</h3>
<h4>Heading 4</h4>

Sizes

ElementSize
h1clamp(1.375rem, 3.5vw, 2rem)
h21.375rem
h31.125rem
h41rem
Use a single h1 per page. Nest headings semantically without skipping levels.

Body text

The default body style is 1rem / line-height: 1.6 using the system font stack. Paragraphs inside .page are rendered in var(--muted).

<p>Body text rendered in muted color within the page container.</p></code></pre>

Code

Inline <code> for short code references.

<p>Use the <code>.button</code> class for actions.</p></code></pre>

Block-level <pre><code> for multi-line examples.

<pre><code>.my-class {
  color: var(--text);
}</code></pre></code></pre>

Tables

Tables are styled with subtle borders and muted text. Max width is 640px.

<table>
  <thead><tr><th>Feature</th><th>Status</th></tr></thead>
  <tbody>
    <tr><td>Auth</td><td>Stable</td></tr>
  </tbody>
</table></code></pre>

Links

Links use var(--accent) by default. Underline appears on hover.

<a href="/docs">Documentation</a></code></pre>
