Browser support

palmshed/ui targets modern browsers and follows a progressive enhancement approach.

CSS features used

palmshed/ui uses the following CSS features, all well-supported in modern browsers:

FeatureMinimum support
CSS custom properties (variables)Chrome 49+, Firefox 31+, Safari 9.1+
:focus-visibleChrome 86+, Firefox 85+, Safari 15.4+
clamp()Chrome 79+, Firefox 75+, Safari 13.1+
flex layoutsChrome 29+, Firefox 28+, Safari 9+
System font stackAll modern browsers

Progressive enhancement

In older browsers that don't support CSS custom properties, the design system degrades gracefully. Content remains readable - colors and fonts fall back to browser defaults. No JavaScript is required for the layout or components to function.

Testing

All changes should be tested in at least Chrome and Safari before merging. For major releases, test in Firefox and Edge as well.
